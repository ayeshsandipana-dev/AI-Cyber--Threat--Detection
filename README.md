# AI Cyber Threat Detection System
> Machine Learning-Based Network Security Monitoring

## 📌 About This Project
This project uses machine learning to analyze network traffic data and detect potential cyber threats, including DDoS attacks. Built as an educational project to demonstrate cybersecurity concepts and threat detection.

## 🛠️ Technologies Used
- *Python 3.x*
- *Streamlit* — Web interface
- *Scikit-learn* — Machine Learning (Random Forest)
- *Pandas* — Data processing

## 📂 Dataset
- *CSE-CIC-IDS2017* — Network Traffic Dataset
- Upload CSV files to analyze traffic patterns and detect anomalies.

## 🚀 How to Run
```bash
streamlit run app.py
